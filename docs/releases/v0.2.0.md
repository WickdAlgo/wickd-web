# Release v0.2.0

- **Status:** Draft
- **Target channel:** Cloudflare Workers Builds deployment of `main`
- **Target date:** when scope completes
- **Prereleases:** `0.2.0-preview.N` versions may ship under this contract
  while the platform routes stabilize.

Turns the platform surface from a demonstration into the frontend host for the
Wickd platform: addressable routes, versioned contracts behind a gateway, a
real chart renderer, and causal replay proven end to end on fixture data.

`v0.1.0` ships the marketing surface and the shell as an illustration. This
contract keeps every claim in that one true while changing what the shell is
underneath. It ships no backend and no real market data.

Architecture: `docs/architecture/001-platform-and-journal-boundaries.md`.
Source decision: `Wickd_Web_Integrated_Trade_Journal_Handoff.md`, phases W0–W5.
Delivery: `docs/sprints/2026-08-01-sprint-2.md`.

## Scope: Includes

- Platform boundaries recorded as an architecture decision, and `PRODUCT.md`
  amended to describe the platform surface as a frontend host — `WEB-BL-007`.
- Nested App Router routes under `/platform`, with a shared layout and a
  sidebar whose active state derives from the URL — `WEB-BL-008`.
- Provisional, versioned, runtime-validated `InspectionDataset` and
  `ChartScene` contracts, plus the journal DTOs — `WEB-BL-009`.
- A `PlatformGateway` interface with a fixture implementation; every platform
  view consumes the gateway rather than module-level mock arrays —
  `WEB-BL-009`.
- A TradingView Lightweight Charts renderer for the platform, with
  token-driven overlay primitives for markers, levels, zones, connections, and
  range highlights — `WEB-BL-010`.
- Final and Causal inspection views with an as-of replay cursor, shareable
  through URL search parameters — `WEB-BL-011`.
- One fixture trade-detail view combining structures, a mentor plan with a
  historical stop update, actual fills, and a synchronized timeline —
  `WEB-BL-012`.
- A test layer — Vitest, React Testing Library, and one Playwright workflow
  spec — running in CI — `WEB-BL-001`.
- The platform surface states that its data is illustrative — `WEB-BL-004`,
  and the `text-[#d7e0e2]` literals in the platform views — part of
  `WEB-BL-006`.

## Scope: Excludes

- Any backend, API route, authentication, or persisted user data. The
  `HttpPlatformGateway` is handoff phase W7 and depends on a `wickd-dotnet`
  API that does not exist yet.
- Real market data or a live engine connection. All content remains generated
  or fixture data and must read as illustration.
- The remaining journal pages — trade list filters, quick capture, review form
  — and the accounts, risk, research, data-quality, and settings routes.
  Handoff phase W6, not yet groomed.
- Authoritative PnL, R, risk, or portfolio computation in frontend code. The
  fixture states these values; React never derives them.
- The `packages/*` workspace split. Contracts and the chart live under `src/`
  behind a one-way import boundary until that boundary has proven stable.
- The rest of `WEB-BL-006` — the hero background literals, the favicon
  decision, and the validator rule — which stay on `v0.1.0`.

## Acceptance Criteria

- [ ] Every platform view has its own address; `/platform` resolves to a
  default view; navigating updates the URL and the sidebar's active state.
- [ ] The platform chart renders real timestamped candles, and its canvas is
  painted rather than blank at its default size.
- [ ] `CandleChart` is no longer the platform inspection renderer, and still
  serves the marketing routes unchanged.
- [ ] No platform view imports a fixture array directly; all data arrives
  through `PlatformGateway`.
- [ ] A payload declaring an unsupported schema version is rejected before
  anything renders, with an error naming the contract.
- [ ] One inspection fixture renders structure primitives across all layers,
  and layer toggles add and remove them.
- [ ] One trade fixture renders its entry zone, historical stop, targets,
  invalidation, and actual fills.
- [ ] Moving the replay cursor before the stop update removes the new stop,
  later fills, and later signal events from both the chart and the timeline.
- [ ] The view states plainly whether it is showing Final or Causal as of a
  timestamp.
- [ ] Selecting a structure reveals its evidence and relations; selecting a
  fill reveals its execution detail.
- [ ] Mentor-reported R and actual net R render as separate, separately
  labeled values.
- [ ] A visitor cannot mistake the platform for a running product, at desktop
  and mobile width — `WEB-BL-004`.
- [ ] Every route renders without console errors at desktop and mobile widths,
  and animated surfaces degrade under `prefers-reduced-motion: reduce`.
- [ ] The web version marker still renders in the platform sidebar, and
  `docs/releases/README.md` names its real location.
- [ ] `PRODUCT.md`, `AGENTS.md`, and `docs/development-cycle.md` describe the
  shipped surface, including the existence of a test suite.
