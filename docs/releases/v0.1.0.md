# Release v0.1.0

- **Status:** Draft
- **Target channel:** Cloudflare Workers Builds deployment of `main`
- **Target date:** when scope completes
- **Prereleases:** The site currently declares `0.1.0-preview`. Further
  `0.1.0-preview.N` versions may ship under this contract.

First stable version of the web surface: the marketing routes and the platform
shell, both built entirely on the design system, with the development cycle
that governs everything after it.

## Scope: Includes

- Marketing surface — home, engine, pricing, and the `/design` showcase —
  sharing one nav and footer shell.
- Platform shell with sidebar-switched inspect, backtest, and dataset views,
  presented honestly as a demonstration of the intended workflow.
- The `src/components/ui/` component library as the shared vocabulary, fully
  re-exported through its barrel.
- Design tokens as the only styling source: no hex literals outside
  `src/app/globals.css`.
- Web and Wickd.Core version markers in the site chrome, with the Core version
  synced from wickd-dotnet releases.
- The development cycle and document hierarchy —
  `docs/sprints/2026-08-01-sprint-1.md`.

## Scope: Excludes

- Any backend, API route, account, or persisted user data — `PRODUCT.md`
  boundary, not a backlog item.
- Real market data or a live engine connection; charts and journals remain
  generated illustrations.
- Waitlist or lead capture on the pricing page — backlog.
- An automated test suite — `WEB-BL-001`.
- Content or claims for the `Platform` and `Agents` tiers beyond their stated
  availability.

## Acceptance Criteria

- [ ] Every route renders without console errors at desktop and mobile widths.
- [ ] Every animated surface degrades correctly under
  `prefers-reduced-motion: reduce`.
- [ ] No hex color literal appears outside `src/app/globals.css`.
- [ ] Every component exported from `src/components/ui/index.ts` appears in the
  `/design` showcase or is classified as site chrome — `WEB-BL-003`.
- [ ] The chrome shows the `package.json` version and the `core-version.json`
  version, and both match their sources on the live site.
- [ ] No page claims capability the engine does not have; unavailable tiers are
  labeled as such.
- [ ] `README.md`, `AGENTS.md`, `PRODUCT.md`, and `DESIGN.md` describe the
  shipped surface, and every documented link resolves.
